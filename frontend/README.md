# 🧊 3Dimg Frontend — AntiGravity Multi-Agent 3D Generation UI

> Next.js 16 (App Router), React 19, Three.js (React Three Fiber) 기반의 대화형 2D to 3D AI 모델 생성 웹 애플리케이션입니다.

---

## 🛠️ 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```

`http://localhost:3000` 접속 후 2D 이미지를 업로드하여 AI 대화 및 3D 모델 생성을 테스트할 수 있습니다.
