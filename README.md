# 3Dimg
---
**Day 1: 프론트엔드 뼈대 구축 및 안티그래비티 기본 세팅**

* **목표:** UI 레이아웃 완성 및 에이전트 파이프라인 설계
* **Next.js (App Router) 기반 Split-View UI 구현:** 좌측(이미지 업로드/챗봇), 우측(3D Canvas) 레이아웃 고정
* **이미지 전처리 연동:** 2D 이미지 업로드 및 배경 자동 제거(RemBg API) 파이프라인 연결
* **AntiGravity 에이전트 스키마 정의:** Vision Agent(분석) 및 Dialogue Agent(질의)의 입출력 JSON 구조 설계

**Day 2: 안티그래비티 오케스트레이션 & 대화 흐름 연동**

* **목표:** 이미지 업로드 후 챗봇과 자동 구체화 대화 작동
* **Vision Agent - Dialogue Agent 체이닝:** 업로드된 이미지 수치화 데이터가 챗봇 시스템 프롬프트로 자동 전달되도록 구성
* **대화형 UI 구축:** LLM 스트리밍 응답 적용 및 유저의 보완 답변(뒷면/재질/스타일)을 수집하는 대화 세션 구현
* **3D Prompt Agent 구축:** 대화 수집 완료 시 3D 생성용 최종 프롬프트 및 파라미터 JSON을 자동 추출하는 로직 완성

**Day 3: 3D 생성 API 연동 & WebGL 뷰어 탑재**

* **목표:** 대화 결과 기반 실제 3D 모델 생성 및 화면 렌더링
* **Three.js (React Three Fiber) 뷰어 연동:** `.glb` 파일 360도 회전, Zoom, Lighting 조작 기능 구현
* **3D API 파이프라인 연결:** AntiGravity 3D Prompt Agent의 출력을 3D 생성 엔진(Tripo3D / Meshy API)으로 전달하고 생성된 `.glb` URL 수신
* **비동기 생성 UX 구현:** 3D 생성 대기 시간 동안 챗봇 로딩 애니메이션 및 Progress 표시

**Day 4: End-to-End 파이프라인 통합 & 예외 처리**

* **목표:** [업로드 ➔ 대화 ➔ 3D 생성 ➔ 내보내기] 전체 흐름 완결
* **전체 유저 여정 연결:** [이미지 업로드] ➔ [AI 질의응답 3~4회] ➔ [3D 생성] ➔ [WebGL 검토] ➔ [GLB 파일 다운로드] 전체 파이프라인 통합
* **예외 처리 & 폴백(Fallback):** 이미지 배경 제거 실패 시 원본 사용 로직, 3D API 타임아웃 예외 처리
* **대화 속도 최적화:** 안티그래비티 멀티 에이전트 간 오버헤드 단축 및 프롬프트 경량화

**Day 5: UI/UX 디테일 다듬기 & 데모 배포**

* **목표:** 서비스 완성도 제고 및 실제 배포
* **데모용 샘플 데이터 세팅:** 초기 유저를 위한 추천 프롬프트 및 예시 이미지 3~4개 미리 구성
* **UI 스타일링:** 버튼, 대화창, 3D 뷰어 툴바 디테일 완성 (Tailwind CSS / Shadcn UI)
* **Vercel 배포 및 최종 QA:** 클라이언트 배포, API 키 환경변수 세팅, 모바일/데스크톱 반응형 최종 검증

## 🎉 [오늘 구현 완료] 5일치 멀티 에이전트 파이프라인 개발 요약

위 5일간의 개발 플랜 전 과정을 **AntiGravity AI 페어 프로그래밍**을 통해 하루 만에 100% 통합 완성했습니다.

### 🤖 1. AntiGravity Multi-Agent 아키텍처
- **Vision Agent**: 2D 이미지 멀티모달 분석 (객체명, 소재, 색상 팔레트, 추천 3D 스타일 추출)
- **Dialogue Agent**: Vision 분석 기반 맞춤 질의응답 진행 (추천 선택 칩, 1초 대화 생략 3D 생성 버튼)
- **3D Prompt Agent**: Vision + 대화 수집 데이터를 합성하여 3D AI 엔진용 최종 프롬프트 및 파라미터 JSON 생성

### ✂️ 2. 3중 배경 자동 제거 (Background Removal Pipeline)
- **1단계**: Remove.bg API 연동
- **2단계**: 외부 API 키 부재/실패 시 온디바이스 AI (`@imgly/background-removal`) 실행
- **3단계**: 스마트 캔버스 알파 매팅 (Canvas Matting) 알고리즘으로 외부 API 키 없이도 100% 투명 배경 PNG 지원

### 🌐 3. WebGL 3D Canvas 뷰어 & 조명 컨트롤러
- Three.js (R3F) 기반 360도 회전/확대/축소 OrbitControls
- 소프트 맑음, 무음영 평면, 스튜디오, 따뜻한 석양 등 4가지 조명 프리셋 & 밝기/그림자 슬라이더 조절
- WebGL 에러 바운더리(`ThreeErrorBoundary`) 및 `.glb` 3D 모델 원클릭 다운로드

### 🛠️ 4. 주요 버그 수정 및 UX 개선
- **대화 상태 보존**: 탭(`이미지` ↔ `AI 대화`) 전환 시 컴포넌트 마운트 유지를 통해 기존 대화 내용 완벽 보존 (새 이미지 업로드 시에만 자동 리셋)
- **식별자 오류 해결**: `lucide-react` 패키지의 `Zap` 컴포넌트 누락 수정
- **업로드 편의성**: 업로드 완료 후 **"다른 이미지 업로드 / 변경하기"** 버튼 추가

```bash
cd frontend
npm install
npm run dev
```
